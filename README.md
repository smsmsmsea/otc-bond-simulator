# 장외채권 시뮬레이터

한국 장외채권(OTC) 시장의 딜러 RFQ·협상 구조를 체험하는 모의 트레이딩 시뮬레이터입니다.

## 데이터

`data.json`은 매일 GitHub Actions가 한국은행 ECOS Open API에서 아래 데이터를 가져와 자동으로 갱신합니다.

- 국고채 3년·10년 금리 (817Y002)
- 회사채 AA-·BBB- 3년 금리 (817Y002)
- 한국은행 기준금리 (722Y001)
- 원/달러 환율 (731Y001)
- KOSPI 지수 (802Y001)

이 데이터로 신용스프레드·금리 변동성·환율·주가지수를 반영한 "시장 스트레스 지수"를 계산해 딜러들의 호가 스프레드와 협상 태도에 반영합니다.

## 구조

- `index.html` — 시뮬레이터 본체 (정적 HTML/JS, 빌드 과정 없음)
- `data.json` — 매일 자동 갱신되는 시장 데이터 스냅샷
- `scripts/update_data.py` — ECOS API 호출 및 `data.json` 생성 스크립트
- `.github/workflows/update-data.yml` — 매일 실행되는 GitHub Actions 워크플로

## 참고

딜러 호가·협상 로직은 모의(simulation) 로직이며 실제 시장 데이터를 반영하지 않습니다. 금리·환율·주가지수만 실제 데이터입니다.
